## Portfolio

Olen neljännen vuoden tietotekniikan opiskelija Satakunnan ammattikorkeakoulusta ja etsin ensimmäistä työpaikkaa datan parissa. Opinnoissani olen erikoistunut tietokantoihin, data-analytiikkaan, koneoppimiseen ja Python-ohjelmointiin.

### Taidot:

* Tietokannat: SQL, NoSQL (MongoDB, Redis), vektoritietokannat (ChromaDB, Pinecone)
* Data-analytiikka: Python, R, Excel, Power BI
* Pilvipalvelut: Azure, Fabric, Snowflake

### Projektit:

1. [Vektoritietokannan ja monikielisen RAG (Retrieval-Augmented Generation) -putken rakentaminen](https://github.com/BrendonKaukonummi/StarTrek-RAG) (in progress)
2. [Tietokannan ohjelmallinen käyttö (PostgreSQL, MongoDB, Redis, Alembic)](https://github.com/BrendonKaukonummi/projecthub)
3. [Markkina-analyysi ja hintaennuste Lontoon Airbnb-asunnoista](https://github.com/BrendonKaukonummi/london-airbnb)

Vapaa-ajallani suoritan seuraavia [Dataquest](https://www.dataquest.io)-sivuston sertifikaatteja:
* Data Engineer

* AI Engineer
* Data Analyst in R
